Medverse24

**Why It Was Built**
Medverse24 was created to bridge the gap between complex medical diagnoses and patient understanding. My goal was to empower patients in Lagos, Nigeria, and beyond to comprehend their symptoms and conditions through clear, AI-driven insights, fostering better engagement with their healthcare journey.

**What Was Built**
Medverse24 is an AI-powered chat platform that delivers accessible, accurate explanations of medical conditions and symptoms. It features an intuitive chat interface for real-time interaction and a curated knowledge repository, making medical information approachable for all users.

**How It Was Built**
Frontend: Built with React for a dynamic, responsive UI, enhanced by React Router for seamless navigation.

Styling: Uses Tailwind CSS for a modern, responsive design, with Material-UI components and icons for an intuitive user experience.

API Integration: Leverages Axios to connect with a backend (hosted on Render) for AI-driven medical insights.

Deployment: Hosted on Netlify for fast, reliable performance.

**Key Features:**
AI-powered chat for explaining diagnoses and symptoms.
Organized medical knowledge repository.
Responsive, user-friendly interface with Material-UI components.
Tech Stack: React, Tailwind CSS, Material-UI, Axios, Netlify.
